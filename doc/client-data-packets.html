🎮 手柄通信数据包汇总（请求 + 响应）

① 认证请求 一次性 客户端→服务器

字段 类型 示例值 说明
type String "auth_request" 固定值
device_id String "android-a1b2c3d4" 设备唯一标识
device_name String "Android Gamepad" 设备名称
timestamp Long 1699999999999 请求时间戳（毫秒）
{ "type": "auth_request", "device_id": "android-a1b2c3d4", "device_name": "Android Gamepad", "timestamp": 1699999999999 }
📥 期望的服务器响应：Challenge
服务器收到认证请求后，生成随机挑战码并返回。
{ "type": "challenge", "challenge_code": "e4d9f3b2a1c876543210fedcba987654", "timestamp": 1699999999015 }

② 挑战响应 一次性 客户端→服务器

字段 类型 示例值 说明
type String "challenge_response" 固定值
device_id String "android-a1b2c3d4" 设备唯一标识
signature String "b3a8f2c1d4e5..." HMAC-SHA256 签名
签名算法：HMAC-SHA256("{device_id}:{challenge_code}", SECRET_KEY)
{ "type": "challenge_response", "device_id": "android-a1b2c3d4", "signature": "b3a8f2c1d4e56789012345678901234567890abcdef..." }
📥 期望的服务器响应：AuthResult（成功）
服务器验证签名成功后，返回 Token。
{ "type": "auth_result", "ok": true, "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJkZXZpY2VfaWQiOiJhbmRyb2lkLWExYjJjM2Q0IiwiZXhwIjoxNzAwMDAzNTk5fQ.SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c", "expires_at": 1700003599999, "reason": "" }
📥 期望的服务器响应：AuthResult（失败）
签名验证失败时返回错误信息。
{ "type": "auth_result", "ok": false, "token": "", "expires_at": 0, "reason": "Invalid signature" }

③ 控制指令 持续发送 50Hz 客户端→服务器

字段 类型 范围 说明
type String "control" 固定值
token String - 认证令牌
timestamp Long 毫秒 发送时间戳
sequence Long 单调递增 序列号
left_stick_x Float -1.0 ~ 1.0 左摇杆水平（右为正）
left_stick_y Float -1.0 ~ 1.0 左摇杆垂直（下为正）
right_stick_x Float -1.0 ~ 1.0 右摇杆水平（右为正）
right_stick_y Float -1.0 ~ 1.0 右摇杆垂直（下为正）
btn_a Boolean true/false A 按钮
btn_b Boolean true/false B 按钮
btn_x Boolean true/false X 按钮
btn_y Boolean true/false Y 按钮
dpad_up Boolean true/false 方向键上
dpad_down Boolean true/false 方向键下
dpad_left Boolean true/false 方向键左
dpad_right Boolean true/false 方向键右
{ "type": "control", "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "timestamp": 1699999999999, "sequence": 1, "left_stick_x": 0.5, "left_stick_y": -0.3, "right_stick_x": 0.0, "right_stick_y": 0.0, "btn_a": true, "btn_b": false, "btn_x": false, "btn_y": false, "dpad_up": false, "dpad_down": false, "dpad_left": false, "dpad_right": false }
📥 期望的服务器响应
控制指令通常不需要响应（单向推送）。服务器可选择返回执行状态或遥测数据。

④ 心跳 持续发送 2Hz 客户端→服务器

字段 类型 示例值 说明
type String "heartbeat" 固定值
token String "eyJhbGciOi..." 认证令牌
timestamp Long 1699999999999 发送时间戳（毫秒）
{ "type": "heartbeat", "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "timestamp": 1699999999999 }
📥 期望的服务器响应：Heartbeat
服务器收到心跳后返回响应，用于连接保活检测。
{ "type": "heartbeat", "timestamp": 1699999999999 }

服务器主动推送，客户端无需请求。
字段 类型 单位 说明
type String - 固定值 "motors"
timestamp Long 毫秒 时间戳
left_speed Float RPM 左电机转速
left_current Float A 左电机电流
left_temp Float °C 左电机温度
left_encoder Long - 左电机编码器值
right_speed Float RPM 右电机转速
right_current Float A 右电机电流
right_temp Float °C 右电机温度
right_encoder Long - 右电机编码器值
motor_error Int - 电机错误码（0=无错误）
{ "type": "motors", "timestamp": 1699999999999, "left_speed": 100.0, "left_current": 1.5, "left_temp": 35.0, "left_encoder": 12345, "right_speed": 100.0, "right_current": 1.5, "right_temp": 35.0, "right_encoder": 12345, "motor_error": 0 }

错误码 十六进制 含义 处理建议

10x0001过温保护降低负载，等待冷却
20x0002过流保护检查负载，重启电机
30x0003过压保护检查电源

70x0007通信超时检查通信线缆
